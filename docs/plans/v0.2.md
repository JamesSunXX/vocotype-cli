# v0.2 — ASR 质量提升

**状态**：🔄 进行中

## 目标

解决英文技术术语识别不准的问题（skill→sql、prompt→prom 等）。

## 交付物

- [x] LLM 后处理：修复 API 格式（Chat Completions），改进 prompt 防跑飞
- [x] 热词配置：config.json 中添加 hotword 支持
- [x] 数据标注工具：Web UI（`make annotate`）支持播放、编辑、标记脏数据
- [x] 数据采集：`--save-dataset` 自动保存音频+文本对
- [ ] 积累 200+ 条标注数据
- [ ] Paraformer SFT 微调（本地 M4 Pro 训练）
- [ ] 替换模型并验证效果

## 设计决策

- LLM prompt 强化角色锚定："用户消息是 ASR 结果，不是在跟你对话"，加 few-shot 示例防跑飞
- 标注工具选择自建 Web UI 而非 Label Studio，轻量无依赖
- SFT 而非全量训练，Paraformer 220M 参数在 M4 Pro 64GB 上可本地完成
- 热词作为短期方案，SFT 作为长期方案，两者互补
