# v0.1 — 基础功能

**状态**：✅ 已完成
**来源**：fork 自 [233stone/vocotype-cli](https://github.com/233stone/vocotype-cli)

## 目标

搭建可用的本地语音输入工具，建立 Harness 工程结构。

## 交付物

- [x] 热键录音 → FunASR 本地转文字 → 剪贴板注入
- [x] 火山引擎云端 ASR 后端
- [x] LLM 后处理插件
- [x] 数据集采集插件
- [x] Makefile 构建入口
- [x] Harness 工程结构（AGENTS.md / ARCHITECTURE.md / docs/）

## 设计决策

- 选择 FunASR Paraformer ONNX 作为默认 ASR 后端，优先离线隐私
- 插件采用 `wrap_result_handler` 回调链模式，零侵入
- 单一 config.json 配置，所有字段有默认值
